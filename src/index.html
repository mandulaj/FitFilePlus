Drop a .fit, .gpx, .tcx or .kml file anywhere on this page
Supported files
.fit — best choice. The only format with running-form metrics (ground contact time, stride height, stride ratio, L/R balance), power, laps and pauses exactly as the watch recorded them.
.tcx — track, elevation, heart rate, cadence and laps.
.gpx — track, elevation and time; heart rate and cadence if the exporter added them. No laps.
.kml — track shape and elevation only, usually no timestamps (so no pace or durations).

Whatever a file contains is shown; the rest is hidden. Drop a file anywhere on the page or use Open file. Files are read in your browser and never uploaded. The last opened file is remembered in this browser, so reloading the page brings it back (⚙ → Close file forgets it).

Settings (layout, panel sizes, collapsed panels, chart metrics, colours, band edges, map choice) are remembered in this browser. Reset them from the ⚙ menu.

iClick a lap to select it on chart and map; click again to deselect. Drag across several rows to select those laps together.
